### About

Systems and Computer Science Engineer at the National University of Colombia. I build **agentic AI systems, computer vision pipelines, and ML products** that reach production, from industrial defect detection to multi-agent marketing assistants.

Currently working at **[ReshapeX](https://www.reshapex.com/)**, building AI agents for industrial companies.

🇨🇴 Based in Colombia, home to the world's largest variety of butterflies and birds, and the second most biodiverse country on Earth.

### 🎖️ Competitions & Achievements

- **Ecosistema de Datos (MinTIC 2025)**: Team project building a fully reproducible pipeline to process and analyze 330k crime records across Santander. Forecasting (Prophet, SARIMA), spatial hotspot detection (DBSCAN, KDE), and XGBoost risk classification, delivering dashboards and actionable insights for public safety.
- **AI Data Challenge (Source Meridian 2025)**: End-to-end machine learning pipeline for real-world datasets. Team achieved 2nd place overall with a classification system using XGBoost and automated data processing.
- **Training Camp Medellín, Competitive Programming (EAFIT 2024)**: Intensive algorithmic problem-solving camp, representing Universidad Nacional de Colombia.
